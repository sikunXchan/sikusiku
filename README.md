# しくん & ちゃくん バトル (MVP)

Phaser 3 + TypeScript + Vite で作る、ド派手な2Dリアルタイムアクションバトル。
最初のマイルストーンとして、プレイヤー操作の **しくん** vs AI の **ちゃくん** の1対1戦闘を実装。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー起動（ブラウザで http://localhost:5173 ）
```

その他のコマンド:

```bash
npm run build    # 型チェック + 本番ビルド
npm test         # ダメージ計算式の単体テスト (Vitest)
```

## 操作方法

- 移動: `←` `→` または `A` `D`
- ジャンプ: `↑` または `Space`
- 技: `J`（長押しでチャージショット）/ `K`（回避）/ `L`（必殺チャージブレイク）
- 画面下の技ボタンはクリック/タップでも発動可能

HPが0になると勝敗が表示され、クリックまたはSpaceでリスタート。

## 実装済みの仕組み（設計書対応）

- 基礎ステータス HP / ATK / DEF / SPD / LUK
- ダメージ計算式: `basedamage × (ATK / 相手DEF) × 段階倍率`、LUK によるクリティカル
- 技カテゴリー: タックル / かわす / チャージショット / チャージブレイク
- HPバー、ダメージ数値ポップアップ、クリティカル演出
- パーティクル、画面シェイク、ヒットフラッシュ、チャージ光

## ディレクトリ構成

```
src/
  data/        キャラ・技・型定義（データ駆動）
  combat/      ダメージ計算 / Fighter / 技解決
  ai/          ちゃくんのAI
  fx/          エフェクト（パーティクル等）
  ui/          HPバー / ダメージ数値 / 技ボタン
  scenes/      Boot（仮ドット絵生成） / Battle（本編）
  tests/       ダメージ計算式の単体テスト
```
